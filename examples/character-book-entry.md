# 世界书外形条目示例

把下面内容放进角色卡的世界书条目。`keys` 至少两个字符，`comment` 写角色名，正文里出现角色名或关键词时会被选中。

```yaml
keys:
  - 温楚楚
  - 楚楚
comment: 温楚楚
content: |
  基础信息:
    姓名: 温楚楚
    年龄: 22
    身份: 咖啡店店员
  外形与体型:
    身高与骨架: 165cm，骨架纤细，肩窄
    体脂与体型: 偏瘦，腰细，腿部线条柔和
    皮肤: 冷白皮，脸颊薄红
    面部: 鹅蛋脸，左眼下方有一颗泪痣
    发型: 黑色长直发，齐腰，常侧分
    日常外穿: 白色衬衫，黑色百褶裙，米色针织开衫
    鞋袜: 黑色乐福鞋，白色短袜
    配饰: 银色细项链，左手腕黑色发圈
    体态与走姿: 站姿笔直，走路很轻，习惯双手交叠在身前
    气味: 淡淡的皂香和咖啡味
```

## 为什么这样写

- `keys` 用于在正文中匹配；太短（1 个字）会被忽略。
- `comment` 也会参与匹配，所以正文出现“温楚楚”时能命中。
- `基础信息` 和 `外形与体型` 是扩展识别的段落。
- `外形与体型` 下只保留这些二级标题：

```text
身高与骨架
体脂与体型
皮肤
面部
发型
日常外穿
鞋袜
配饰
体态与走姿
气味
```

- 包含 `乳房 / 乳头 / 乳晕 / 阴 / 肛门 / 生殖 / 性器 / 体液 / 自慰 / 内衣 / 胸罩 / 内裤 / 下体 / 私处` 的整行会被过滤。

## 最小版本

如果不想写这么细，至少保留：

```yaml
keys: [角色名]
comment: 角色名
content: |
  外形与体型:
    发型: ...
    日常外穿: ...
    面部: ...
```

## 多个角色

每个角色一个条目。扩展按正文中出现的位置排序，最多取 3 个。多人场景建议把最关键的外形放在各自条目的前几行。

## 注意

- 不要放他人的角色卡全文；
- 不要放露骨段落；
- 不要把变量/状态写进外形条目，扩展不会解析它们。
