# 隐私与安全

这个扩展的设计目标是**本地、私密、可控**。默认配置下，聊天内容不会离开你的电脑。但“本地”不等于“绝对安全”，下面把数据流和边界讲清楚。

---

## 1. 数据流

一次自动配图涉及四个进程：

```text
SillyTavern（浏览器 + Node 服务端）
        │
        ├──▶ Ollama（本地 11434）
        │      收到：当前正文 + 角色设定
        │      返回：中文分镜 + 英文提示词
        │
        └──▶ ComfyUI（本地 8188）
               收到：英文提示词 + 负面词 + 工作流参数
               返回：图片 base64
```

### 默认配置下谁会收到什么

| 接收方 | 收到 | 是否离开本机 |
| --- | --- | --- |
| Ollama | 当前 AI 正文、角色卡 Description/Personality/Scenario、匹配到的世界书外形条目 | 否（127.0.0.1） |
| ComfyUI | 英文提示词、负面词、分辨率、步数、种子 | 否（127.0.0.1） |
| SillyTavern 服务端 | 上述请求的代理、生成的图片 | 否 |
| GitHub / 云端 | 无 | 否 |

**不会发送**：

- 完整聊天历史（只取最后一条 AI 正文）
- 用户消息
- 其他角色卡
- SillyTavern 账号密码
- API Key（扩展不读取、不保存）

### 如果你改了地址

以下情况数据会离开本机：

- `llm_url` 改成云端 OpenAI/Claude/其他 API；
- `comfy_url` 改成 RunPod/云 ComfyUI/另一台机器；
- SillyTavern 本身配置了云端聊天模型（扩展只负责生图，不改变聊天模型）。

这时数据会发送到对应服务，遵守对方的隐私政策。README 默认只推荐本地地址。

## 2. 本地服务暴露面

### 默认绑定

建议：

```text
Ollama:   127.0.0.1:11434
ComfyUI:  127.0.0.1:8188
```

不要把它们直接暴露到公网。ComfyUI 默认没有认证，任何能访问 8188 的人都可以提交工作流、读取 `output/` 图片。

### 如果 SillyTavern 要远程访问

推荐顺序：

1. **Tailscale / ZeroTier** 等私有网络，只允许自己的设备；
2. **Cloudflare Tunnel + Access**，加身份验证；
3. 反向代理 + HTTPS + Basic Auth。

不要：

- 直接把 8000/8188/11434 端口映射到公网；
- 用无认证的公网 IP 访问；
- 在公共 Wi-Fi 下开放局域网监听。

### 手机访问

扩展本身不监听端口；手机访问的是 SillyTavern。只要 ST 的远程访问是安全的，扩展不会额外扩大暴露面。

但注意：手机上的浏览器也会执行扩展代码，生成的图片会保存在**服务端**的用户目录，不是手机相册。

## 3. 聊天内容与角色卡

### 会读到什么

- 最后一条 AI 消息的正文（优先 `<game>`）；
- 当前角色卡的 `Description / Personality / Scenario`；
- 角色卡世界书里与正文匹配的最多 3 个条目；
- 角色卡的名字。

### 不会读到什么

- 用户消息；
- 历史消息（除非最后一条本身包含历史摘要）；
- 其他角色卡；
- SillyTavern 设置里的 API Key；
- 系统提示词（扩展不读取）。

### 世界书过滤

`extractVisualProfile()` 会删掉包含以下词的整行：

```text
乳房 乳头 乳晕 阴 肛门 生殖 性器 体液 自慰 内衣 胸罩 内裤 下体 私处
```

这不是完美的内容过滤器，但能避免把最敏感的外形段落发给生图模型。你可以按自己的需要调整。

---

## 4. 图片存储

图片通过 SillyTavern 的 `saveBase64AsFile()` 保存到：

```text
SillyTavern/data/<用户>/user/images/
```

文件名包含角色名和时间戳。图片不会自动上传到任何地方。

删除图片：

- 在 SillyTavern 的图库里删除；
- 或直接删 `user/images/` 下对应文件。

删除聊天不会自动删除图片文件；需要手动清理。

---

## 5. 日志

### 浏览器 Console

打开“调试日志”后，会打印：

- 消息索引
- 最终英文提示词（包含角色外形描述）
- 错误堆栈

这些日志只在本地浏览器 Console，不会上传。分享截图/日志前请删掉角色卡内容和提示词。

### SillyTavern 服务端日志

会记录 HTTP 请求路径和错误，通常不记录完整请求体。ComfyUI 控制台会打印工作流节点和可能的提示词。

### ComfyUI 输出

`ComfyUI/output/` 会保留生成的 PNG。默认文件名由 `SaveImage` 节点决定，可能包含时间戳。

## 6. 内容边界

### 默认模板

仓库默认的第一段提示词是**非露骨版**：

```text
用姿势、距离、衣物状态和表情表现人物关系；不描写露骨性行为。
```

原因：

- 这是公开仓库，需要遵守 GitHub 的可接受使用政策；
- 默认模板要能被大多数人直接使用；
- 露骨内容应该由使用者明确选择，而不是安装后自动开启。

### 私有使用

你可以在本地把第一段改成允许更露骨的描写。请注意：

1. **不要**把这类改动提交到公开仓库；
2. **不要**生成涉及未成年人的性内容；
3. 遵守你所在地区的法律；
4. 遵守模型许可证（有些模型禁止色情/暴力用途）；
5. 不要把生成内容上传到你没有权限的平台。

### 角色卡版权

角色卡、世界书、人物设定可能受版权保护。扩展只在本机读取；分享配置/截图时不要附带他人的角色卡全文。

- [ ] 公开仓库不要提交 `data/`、模型、生成图、`settings.json`

## 9. 威胁模型（简化）

这个扩展**不能**防御：

- 已经控制你电脑的攻击者；
- 恶意角色卡通过提示词注入让 LLM 输出奇怪内容（最多影响生图提示词，不会执行代码）；
- 恶意 ComfyUI 自定义节点（它们运行 Python，拥有你的用户权限）；
- 恶意 SillyTavern 第三方扩展；
- 你主动把服务暴露到公网后被扫描。

它能做的：

- 不把聊天历史发给生图模型；
- 不把数据发给云端（默认配置）；
- 限制读取的世界书条目数量和字段；
- 生成失败时不破坏聊天记录；
- 切换聊天时丢弃图片，避免贴错会话。

## 10. 删除数据

### 删除扩展

```powershell
powershell -ExecutionPolicy Bypass -File .\uninstall.ps1 -SillyTavernPath "D:\SillyTavern"
```

设置仍保留在 `settings.json` 的 `extension_settings.k2auto`。彻底删除：

1. 关闭 SillyTavern；
2. 编辑 `data/default-user/settings.json`，删掉 `k2auto` 字段；
3. 重启。

### 删除生成图片

```text
SillyTavern/data/default-user/user/images/
```

### 删除 ComfyUI 输出

```text
ComfyUI/output/
```

### 删除日志

浏览器 Console 日志关闭页面即清空；服务端日志按你的日志配置清理。
